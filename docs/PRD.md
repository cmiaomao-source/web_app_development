# 讀書筆記本專案 - 產品需求文件 (PRD)

## 1. 專案概述
- **背景與動機**
  現代人閱讀書籍後經常忘記重點，需要一個專屬的空間記錄讀書心得、整理書單與評分，方便日後回顧、查找與分享。
- **目標用戶**
  所有人（喜歡閱讀、需要做筆記的學生、上班族等）。
- **核心價值主張**
  提供一個簡單、好用的介面，讓使用者可以快速記錄書本資訊、心得與評分，並能輕鬆搜尋過去的筆記與進行評論互動。

## 2. 功能需求
以下為本專案的主要功能清單：

1. **記錄書名與新增筆記**
   - 作為 **讀者**，我希望 **能夠輸入書名並記錄我的讀書心得**，以便 **完整儲存我對這本書的看法與知識點**。
2. **評分系統**
   - 作為 **讀者**，我希望 **能夠為每本書打分數 (例如 1-5 顆星)**，以便 **快速辨識我對該書的推薦程度與喜好**。
3. **筆記列表展示**
   - 作為 **讀者**，我希望 **能在首頁或專屬頁面看到所有歷史讀書筆記**，以便 **隨時回顧我過去讀過的書單**。
4. **筆記搜尋功能**
   - 作為 **讀者**，我希望 **能用書名、關鍵字或心得內容搜尋筆記**，以便 **在大量筆記中快速找到特定書籍的紀錄**。
5. **評論與互動 (可評論)**
   - 作為 **讀者**，我希望 **能夠在筆記下方留言評論**，以便 **紀錄後續的補充想法，或是與其他使用者交流討論**。

## 3. 非功能需求
- **技術限制**
  使用 Flask 作為後端框架，Jinja2 作為前端模板引擎，搭配 SQLite 作為關聯式資料庫。
- **效能與安全考量**
  - 搜尋功能需優化查詢速度，確保即使筆記數量增加也能快速回傳結果。
  - 防範常見的網路攻擊（如防止 SQL Injection 以及針對評論區的 XSS 攻擊）。

## 4. MVP 範圍 (最小可行性產品)
- **Must Have (必須有)**
  - 記錄書名與心得內容
  - 書籍評分功能
  - 基本的筆記列表展示
- **Should Have (應該有)**
  - 依據書名或內容進行搜尋的功能
- **Nice to Have (可以有)**
  - 筆記評論留言功能
  - 依評分高低或時間排序筆記列表
